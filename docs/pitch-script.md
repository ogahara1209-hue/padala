# Padala — 1-minute pitch script

**0:00-0:15**

Hi, I'm Kanji, and I'm building Padala. Filipino workers in Japan can buy USDC at registered exchanges like SBI VC Trade. But under its published rules, it can't be withdrawn directly to GCash in the Philippines.

> こんにちは、Padala を作っている Kanji です。日本で働くフィリピン人は、SBI VC トレードのような登録業者で USDC を買えます。しかし、その公開された規定では、フィリピンの GCash へ直接は出庫できません。

**0:15-0:30**

So the sender needs their own wallet in between. Padala is that wallet. Only the sender holds the key. Padala never holds keys or funds.

> そのため、送り手は間に自分の財布が必要です。Padala がその財布です。鍵を持つのは送り手だけで、Padala は鍵もお金も預かりません。

**0:30-0:48**

The sender signs one EIP-3009 authorization. My relayer submits it and pays the gas, but it can't change the recipient or the amount. The sender needs only USDC, and the family converts it to pesos inside GCash.

> 送り手は EIP-3009 の認可に一度署名するだけです。私のリレーサーバーが送信してガス代を払いますが、送り先と金額は変えられません。送り手に必要なのは USDC だけで、家族は GCash の中でペソに替えます。

**0:48-1:00**

It works end to end on Ethereum's Sepolia testnet today. Next, I'll test it with real families. Thank you.

> 今日、Ethereum の Sepolia テスト網で端から端まで動いています。次は実際の家族と試します。ありがとうございました。
